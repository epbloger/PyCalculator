## ✨ What can it do?

The calculator can perform basic arithmetic operations:

| Operator | Operation |
|---|---|
| `+` | Addition |
| `-` | Subtraction |
| `*` | Multiplication |
| `/` | Regular division |
| `//` | Integer division |
| `**` | Exponentiation |
| `%` | Finding the remainder of division |
